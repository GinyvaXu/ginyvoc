# GinyScreen 需求说明

## 项目目标
做一个"联机游戏语音频道 + 屏幕共享"一体的语音软件（GinyScreen），参考 Discord / Mumble /
TeamSpeak 等现有产品与 GitHub 开源库，先做可自托管、可运行的 Web 版，后续可打包桌面端。

## 核心需求

### R1 房间与会话
- R1.1 用户输入昵称即可创建/加入房间，无需注册。
- R1.2 房间使用 5 位邀请码（去易混淆字符），支持复制邀请链接。
- R1.3 房间内多个语音频道，成员可自由进出/切换频道。

### R2 语音通话
- R2.1 同频道成员实时互通语音，低延迟（Opus）。
- R2.2 支持三种说话模式：语音检测(VAD)、按键说话(PTT)、自由麦。
- R2.3 支持单独静音（麦克风关）与完全闭麦（不听不说）。
- R2.4 显示"正在说话"指示与音量表。

### R3 屏幕共享
- R3.1 可共享整个屏幕/窗口/标签页，多人可同时共享。
- R3.2 共享者停止共享后，观看端画面自动移除。

### R4 辅助
- R4.1 房间内文字聊天。
- R4.2 音频输入设备可选、VAD 灵敏度可调、PTT 按键可自定义。

## 非功能需求
- N1 语音与屏幕画面不经过服务器（P2P），服务器仅信令 → 成本低、隐私好。
- N2 局域网可用（HTTPS 自签名）；公网可部署（TURN 兜底）。
- N3 服务器零配置可跑（npm install && npm start），客户端无构建步骤。
- N4 支持 2~8 人开黑规模；>8 人走 SFU 升级路径。

## 验收标准（v0.1）
1. 两台设备（或双开浏览器）加入同一房间同一频道可通话。
2. 屏幕共享可被同频道成员看到，停止后画面消失。
3. 说话指示灯随 VAD/PTT 正确点亮。
4. 断线/离房后成员列表与连接正确清理。
5. `node scripts/smoke-test.mjs` 12 项断言全部通过。

## 范围外（路线图）
TURN 部署文档、SFU 扩容、降噪增强(RNNoise)、账号/权限、录音、移动端。
